MILESTONE 3 - LOCAL GEMINI VERIFICATION (WINDOWS, POWERSHELL)
=============================================================

Read PROVIDER_SETUP_AR.md first. Nothing here sends your key anywhere except
Google's generativelanguage endpoint, and the key is never printed.

A. ONE-TIME SETUP (run in the repository root)
----------------------------------------------
  1. Node.js 18 or newer is required (Node 20+ recommended).
  2. npm ci --ignore-scripts
  3. npm run build:core
  4. Confirm the core build exists:  dir packages\core\dist\index.js

B. SET THE KEY FOR THIS WINDOW ONLY (paste it yourself; never paste it into chat or a file)
-----------------------------------------------------------------------------------------
  $env:GEMINI_API_KEY = "<paste your key here>"

C. STEP 1 - PREFLIGHT (no generation, not billable as generation)
-----------------------------------------------------------------
  node tools/gemini-verify.mjs --preflight

  Expect JSON with "catalogReachable": true and "textModelListed" / "ttsModelListed".
  "catalogReachable": false means the network or key is the problem.
  This proves CATALOG access only. It does not prove quota, free tier, or generation.

D. STEP 2 - ONE TEXT PLAN (only after you confirm a free-tier key)
------------------------------------------------------------------
  $env:GEMINI_GENERATION_ENABLED = "1"
  $env:GEMINI_FREE_TIER_CONFIRMED = "1"
  node tools/gemini-verify.mjs --text --confirm-free-tier

  Uses a fixed built-in fixture brief. No project file is read or sent.
  At most 2 text requests per session (the second is the single repair).
  Expect "textGenerationOk": true and the three treatment methods.

E. STEP 3 - ONE SPEECH PREVIEW (reviewed text only, 20 seconds at most)
-----------------------------------------------------------------------
  1. Write ONE short line you have reviewed to a file, 350 characters at most:
       notepad reviewed-line.txt
     Save it. Do not put private or unreviewed material in it.
  2. Run:
       node tools/gemini-verify.mjs --speech --confirm-free-tier --reviewed --text-file reviewed-line.txt --language en --voice Kore --profile educational
  3. For Arabic, use --language ar and text that contains Arabic letters.
     Arabic readiness is a SEPARATE evidence state. An English run does not prove Arabic.
  4. Only ONE preview per profile is allowed. At most 2 previews per session.

F. LISTEN, THEN RECORD
----------------------
  Open the WAV in output\gemini-verify\ and listen to it yourself.
  The script does NOT judge audio quality. Its "listened": false is correct until you listen.
  Result file: output\gemini-verify\evidence.json (contains hashes and durations, no key).

G. STOP AND CLEAN UP
--------------------
  Remove-Item Env:GEMINI_API_KEY
  Remove-Item Env:GEMINI_GENERATION_ENABLED
  Remove-Item Env:GEMINI_FREE_TIER_CONFIRMED

H. WHAT A FAILURE MEANS
-----------------------
  401  key rejected                 -> check the key value
  403  access refused               -> check the project and model access
  429  quota or rate limit          -> stopped; no fallback was used; wait or check free-tier limits
  0    network error or timeout     -> try later; nothing was saved
  STOP: ...                         -> a gate stopped the run BEFORE any call

I. DO NOT COMMIT
----------------
  output\ is git-ignored. Do not add reviewed-line.txt, WAV files, or evidence.json to Git.
  Commit source, tests, and docs only.
