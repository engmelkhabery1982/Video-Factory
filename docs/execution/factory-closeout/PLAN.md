## Input acceptance matrix (all within existing canonical draft/editor)
- No material: choose suggested topic from channel purpose, review local script, choose narration or silent.
- Topic only: three meaningfully different reviewed local treatments/scripts; no template-only claim of semantic planning.
- Script only: exact words preserved unless a reviewed derivative is selected; visuals and optional speech completed.
- Audio only: independent local transcription -> correction/review -> scene plan/alignment; no mandatory external transcript.
- Pictures only: ordered silent story or reviewed locally proposed narration; reference vs final-shot roles are explicit.
- Reference pictures plus topic/script: actual pixel-conditioned generation, appropriate consistency and provenance.
- Text storyboard: convenient text/file import, exact ids/locks/wording/times, optional speech and conflict resolution.
- Image/page storyboard: ordered import, reviewed observations, PDF only through an explicit supported parser/approved provisioning decision.
- Video with audio: preserve original, choose original/added/replaced narration explicitly; extraction/review/captions as selected.
- Video without audio: silent remains valid; optional added narration, never forced.
- Mixed/conflicting sources: field authority, explicit review, locks and current revisions; no silent overwrite.
- No narration desired: no voices/transcript/alignment gate and no fabricated subtitle words. Optional licensed existing music.
